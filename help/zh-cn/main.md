# Claude 历险记

> 最后更新：2026-10-01

Claude 历险记是一个 2D 横版平台跳跃小游戏：扮演珊瑚橙色的星芒小家伙 Claude，在 5 个主题关卡里奔跑、跳跃、踩 Bug、发射 `{}` 工具调用，最终在生产环境击败「祖传巨石」。游戏把 AI 编程的梗融进玩法——Token 是金币也是弹药，关卡计时就是上下文窗口，满了就「上下文溢出」。

> 一句话上手：打开 Claude 历险记页面 → 点 **开始冒险** → 用 **← →** 移动、**空格** 跳跃、**X** 发射 `{}`，走到关卡终点亮着 ✓ 的终端即通关。

## 能做什么

- 5 个主题关卡：终端草原（教学）→ 代码丛林 → 依赖地狱 → 云端 → 生产环境（Boss 战）。
- 平台跳跃手感：土狼时间、跳跃缓冲、松键小跳、空中二段跳、弹跳垫。
- 战斗：踩 Bug 的头「修掉」它，或消耗 Token 发射 `{}` 工具调用；锯齿是死循环，碰不得只能躲。
- 上下文窗口机制：顶部进度条就是上下文，随时间增长，满了就死；摘要卷轴（/compact）清掉 35%。
- 检查点与回滚：git 旗是检查点，死亡后从最近的检查点回滚，上下文与 Token 都有保底。
- 进度存档：每关最佳用时 / 最多 Token / 最少阵亡、已解锁关卡、通关次数都记在本机。

## 常见操作

### 开始与选关

- 标题界面：**开始冒险**（从已解锁的最高关继续）/ **选择关卡** / **操作说明**。
- 选关界面：5 张关卡卡片，未解锁的显示 🔒；每张卡片显示最佳用时与最多 Token。
- 菜单都能用鼠标点，也能用 ↑↓ 选择 + Enter 确认。

### 暂停

- **Esc** 或 **P** 暂停，菜单有 **继续** / **重开本关** / **返回标题**。
- 窗口失焦或切到后台会自动暂停。

### 通关与结算

- 走到终点亮着 ✓ 的终端即通关，结算界面显示用时、收集 Token、阵亡数，破纪录会标 ★ NEW。
- 结算界面点 **下一关**（或按 Enter / 空格）进入下一关；第 5 关结算后点 **上线！** 进入结局画面。

## 操作方式

| 按键 | 作用 |
| --- | --- |
| ← → / A D | 移动 |
| 空格 / W / ↑ / Z | 跳跃（空中再按一次 = 二段跳；按住跳得更高） |
| ↓ / S | 从单向平台上跳下去 |
| X / J / K | 发射 `{}` 工具调用（每发消耗 1 个 Token） |
| Esc / P | 暂停 |
| Enter | 确认（菜单） |

页面工具栏还有 **静音** 按钮和 **音量** 滑块，右侧常驻一行操作提示。

## 命令行

进度数据保存在 `~/.config/LinuxCockpit/claudeadv/stats.json`，可用命令读写：

```bash
claudeadv.stats                                   # 读取进度（解锁关卡 / 每关最佳纪录）
claudeadv.record --level 1 --time 83.4 --tokens 21 --deaths 0   # 记一次通关
claudeadv.reset --confirm true                    # 清空全部进度
```

## 常见问题

**Token 用完了怎么办？** Token 既是金币也是弹药：顶 `?` 方块、捡金币都能获得；Boss 战中会定期下 Token 雨。死亡回滚后 Token 保底 3 个。

**上下文窗口满了就死？** 是的，顶部进度条走到 100% 会「上下文溢出」。捡摘要卷轴（/compact）立即清掉 35%，或死亡回滚时上下文会回落到检查点时的值（最高 70%）。

**关卡打不过去？** 已解锁的关卡可以随时从标题界面的 **选择关卡** 重打；每关的最佳纪录独立计算。

**游戏窗口失焦会怎样？** 会自动暂停，不会趁你切走时偷跑计时。
