# 机制详解

> 最后更新：2026-10-01

## Token 与 `{}` 射击

- Token 是金币也是弹药：捡金币、顶 `?` 方块获得，发射 `{}` 每发消耗 1 个。
- 初始 5 个 Token；发射有 0.22 秒冷却。
- Token 不足时发射会提示「Token 不足！」，不会扣成负数。
- `{}` 可以打 Bug、飞虫、Boss，也能顶开 `?` / `!` 方块；打锯齿只会溅火花（它是死循环，修不掉）。
- 踩中敌人后按住跳跃键可以再跳更高。

## 上下文窗口与摘要卷轴

- 画面顶部中央的进度条就是上下文窗口，随时间增长；各关满载时间不同（第 1、2 关 240 秒，第 3、4 关 260 秒，第 5 关 300 秒）。
- 进度条走到 100% 会「上下文溢出」直接阵亡。
- 捡摘要卷轴（/compact）立即清掉 35% 上下文。
- 进度条颜色：<60% 绿、<85% 黄、≥85% 红并闪烁警告。

## 受伤 / 无敌 / 死亡 / 回滚

- 3 颗红心 = 3 点生命。碰到敌人、尖刺、Boss 或它的弹幕会扣 1 点并击退。
- 受伤后有 1.4 秒无敌（画面闪烁）；死亡回滚后出生带 1.5 秒无敌。
- 岩浆一碰即死；掉出地图也会死。
- 死亡后从最近的检查点（git 旗）回滚，规则：
  - 位置回到检查点；
  - 上下文回落到检查点记录时的值，但最高不超过 70%；
  - Token 保底 3 个（不会比回滚前更少）；
  - 清空所有 `{}` 弹体与 Boss 弹幕。
- Boss 战中阵亡：Boss 回满血、回到沉睡状态、闸门重新打开，召唤的 Bug 一并清除。

## 弹跳垫

- 踩上去弹得很高（约 10 格），并补满一次二段跳。
- 路牌写着「npm install --force」。

## 单向平台

- 单向平台（木板 / 云朵）只能从下穿过、从上落下。
- 站在上面按 **↓** 可主动跳下去（有 0.25 秒延迟，期间不会意外下落）。

## 道具块

- `?` 方块：顶出 1 个 Token，用过后变灰。
- `!` 方块：顶出爱心（满血时变成 +3 Token）。
- 从下方撞击才会触发；用 `{}` 打中也能触发。
- 顶块时站在上面的 Bug 会被顺手压死。
